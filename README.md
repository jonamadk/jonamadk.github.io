
# Github Static Host

This repo contains all the files of my portfolio site.

### Description:


* Here I have constructed the static portfolio site implementing the github API to retirve my (user) data and to display it in the site.
  
Followings are the data resources used:

* > User name from data['name]
* > User bio from data['bio]
* > Github user profile link from data['html_url']
* > User Address from data['location]
